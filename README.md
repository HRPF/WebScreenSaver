# WebScreenSaver 屏保管理器

让你的 Windows 桌面拥有丰富多彩的 Web 屏幕保护程序——**自由切换、实时预览、无限扩展**。

## 功能特色

- **多屏保管理**：内置时钟屏保，还可添加更多 Web 屏保，一键切换
- **实时预览**：在配置窗口中即可看到屏保的真实效果
- **独立样式设置**：每个屏保可单独配置外观（颜色、字体等）
- **零配置扩展**：添加新屏保只需新建一个文件夹，放入网页文件即可
- **性能友好**：基于 WebView2 渲染，流畅不卡顿

## 安装方法

> 注意：支持Windows10及以上系统，需要安装Microsoft Webview2组件（大部分系统已内置）

1. 在 [Releases](https://github.com/HRPF/WebScreenSaver/releases) 页面下载最新版本的安装包
2. 运行安装程序
3. 在安装目录中找到 `WebScreenSaver.scr` 文件
4. 右键点击 → 选择 **安装**，将自动打开“屏幕保护程序设置”，选择`WebScreenSaver`，点击 **确定** 或 **应用** 即可



## 使用指南

### 打开主配置页

1. 安装后，打开Windows**屏幕保护程序设置**
2. 选择 `WebScreenSaver`
3. 点击 **配置** 

### 切换屏保

主配置页左侧列出所有已安装的屏保。点击任意屏保名称：
- 右侧会**实时预览**该屏保的效果
- 点击 **样式设置** 可修改该屏保的外观（颜色、字体等）
- 点击 **启用屏保** 将其设为当前屏保


## 如何添加自己喜欢的屏保

你只需要在屏保程序的 `web` 文件夹下创建一个子文件夹，放入你的网页文件：

```
web/                       ← 屏保程序目录下的 web 文件夹
├── index.html             ← 主配置页（不要动）
│
├── 我的粒子效果/           ← 你的屏保文件夹（名称自定）
│   └── index.html         ← 屏保入口文件（必须）
│
├── 3D星球/                ← 另一个屏保
│   ├── index.html         ← 屏保入口
│   └── config.html        ← 可选：样式配置页
```

**要求**：
- 文件夹名称就是屏保在列表中的显示名称
- 文件夹内至少需要有一个 `index.html` 作为屏保入口
- 如果提供 `config.html`，用户可以在主配置页中点击"样式设置"来打开它
- 其他资源文件（CSS、JS、图片等）放在文件夹内，在 `index.html` 中以相对路径引用


## 技术概览

- 基于 **.NET 8 + Windows Forms + WebView2** 构建
- 屏保通过 WebView2 加载，支持所有 Web 前端技术
- 自动发现 `web/` 文件夹下的屏保，无需编辑配置文件
- 屏保选择保存在 `config.json` 中，切换后自动记忆
- 全屏模式下通过全局键盘/鼠标钩子检测用户操作并退出
